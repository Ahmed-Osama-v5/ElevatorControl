void LEDController_vidInit ( void )

Initializes the LEDController module.

Configures the latch and data GPIO lines as outputs, clears all latch outputs, and resets internal LED state tracking.

Initializes the LEDController module.

◆ LEDController_vidProcess()

void LEDController_vidProcess ( void )

Periodic processing task for the LED controller.

Updates blink timers and writes the resulting LED states to the hardware latches. Must be called every cu8LED_CONTROLLER_PERIOD_MS milliseconds.

Periodic processing task for the LED controller.
