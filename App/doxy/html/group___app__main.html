int main ( void )

Application entry point.

Sequence:

  1. Initialize all hardware and software sub-modules via ElevatorController_Init.
  2. Display the splash screen via ElevatorController_vidSplashScreen.
  3. Read the boot mode via ElevatorController_enuGetMode.
  4. If MODE_PROGRAM: enter ElevatorController_vidProgrammingLoop.
  5. If MODE_NORMAL: enter ElevatorController_vidOperationLoop.
Returns
int Always returns 0 (never reached on embedded target).
