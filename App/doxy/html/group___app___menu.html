void Menu_Init ( void )

Initializes the menu system.

Must be called once before any other Menu function. Resets the item list, sets the navigation cursor to the first item, and sets the mode to MENU_MODE_NAVIGATE.

void Menu_Task ( void )

Periodic task handler for the menu system.

Handles timed events such as cursor blinking. Should be called every MENU_BLINK_PERIOD_MS milliseconds.

void Menu_Update ( void )

Processes user input and updates the menu state.

Reads button states to navigate between menu items or increment / decrement the selected item's value while in edit mode. Writes confirmed values to EEPROM.

void Menu_UpdateItemValue ( MenuItemId_t itemId,
uint8_t value )

Updates the stored value of an existing menu item.

Refreshes the runtime value without changing the label or bounds. Useful for reloading a parameter from EEPROM after an external write.

Parameters
itemIdUnique identifier of the menu item (MenuItemId_t).
valueNew value to assign to the item.
