void MotionController_vidMove ( MotionState_t enuState)

Applies a motion command to the elevator drive.

Activates the relay combination that corresponds to the requested MotionState_t. Only one motion state is active at a time; calling this function while the drive is running will switch states immediately.

Parameters
enuStateTarget motion state (see MotionState_t).
