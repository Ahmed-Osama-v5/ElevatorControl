\doxysubsection{Detailed Description}
Public interface for the LEDController module. 

Manages the state and blink patterns of all floor indicator LEDs connected via two 74HC573 octal latches. Provides functions to set individual LED states, assign blink patterns, and run the periodic LED processing task.
