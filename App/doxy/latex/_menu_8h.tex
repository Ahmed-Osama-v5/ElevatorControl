\doxysubsection{Detailed Description}
Public interface for the Menu module. 

Provides an interactive LCD-\/based programming menu that allows technicians to view and modify elevator configuration parameters persisted in EEPROM. The menu is active only in \doxylink{_elevator_controller__gcfg_8h_a6ec00bb6b751b86924505702a0deef09ac0bb14a1652af327eb3738cc6c78149e}{MODE\+\_\+\+PROGRAM}.
